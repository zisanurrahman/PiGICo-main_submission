# 🧬 PiGICo Analysis (SGI- Swine Gut Isolate conbined with PiBac) — Scripts Repository

This repository contains all analysis scripts and pipelines used in the study  
**“Genome-Resolved Profiling of an Expanded Swine Gut Isolate Collection Reveals Functional Signatures of Health and Disease”**  

---

## 📖 Overview

The Swine Gut Isolate (SGI) project aims to uncover the genomic and functional diversity of cultured swine gut bacteria and their associations with host health and disease.  
This repository provides reproducible scripts and workflows used for genome annotation, feature integration, read mapping, machine learning, and network-based guild analysis.

All scripts were executed on the **Grex HPC cluster** and structured for modular use or integration within Snakemake pipelines.

---

## ⚙️ Dependencies

All analyses were performed using **Python 3.12+** and **R 4.3+**.

**Key Python packages:**

pandas, numpy, scipy

scikit-learn, xgboost

matplotlib, seaborn

networkx, tqdm

biopython

**Key R packages:**

tidyverse, dplyr, ggplot2

ComplexHeatmap, patchwork, viridis

vegan, reshape2, rstatix
